# From Spreadsheets to Systems

A companion resource for our ELC 2026 presentation, **From Spreadsheets to Systems: Applying a Data Science Mindset to Physical Therapy Education**.

This resource introduces reproducibility, transparency, automation, version control, data storytelling, and collaborative workflows as tools for improving educational data practices. It includes reflection prompts, a process redesign worksheet, and an R example using fictional student data.

The resource itself demonstrates these principles by combining text, code, and generated results in a Quarto document.

## View or render

Open the rendered HTML in a browser, or open `educational-data-systems.qmd` in RStudio or VS Code with Quarto installed.
